# iPredict Android Demo

- Package: `com.lkl.ipredict`
- Min SDK: `24` (Android 7.0 Nougat)
- Screens: `倒计时 / 日期 / 图表`

## Open

1. Open this folder in Android Studio.
2. Let Android Studio sync Gradle.
3. Run on an emulator/device with Android 7.0+.

> Note: this workspace currently does not include Gradle Wrapper (`gradlew`).
> If needed, generate it from Android Studio or local Gradle first.
